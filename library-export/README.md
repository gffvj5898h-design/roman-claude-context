# ChatGPT Library export

Дата запуска: 2026-09-04.

Цель: перенести в этот приватный репозиторий максимально полный индекс и содержательный контекст файлов из ChatGPT Library — включая документы, таблицы, презентации, архивы, изображения и видео.

## Важное техническое ограничение

Подключённый к ChatGPT GitHub-коннектор умеет создавать UTF-8 текстовые файлы и Git blobs из переданного текста/base64, но **не принимает ChatGPT Library file reference как бинарное вложение напрямую**. Поэтому сотни исходных `.png/.jpg/.pdf/.docx/.xlsx/.pptx/.zip/.mp4` нельзя безопасно и полно скопировать в GitHub одним server-side действием без прогонки каждого бинарного файла через модель/base64. Для большой Library это упирается в ограничения размера и пропускной способности инструмента.

Из этого следует разделение экспорта:

1. `chatgpt-context/` — уже загруженный долговременный контекст и восстановленная история.
2. `library-export/` — полный inventory Library, текстовые извлечения/описания и provenance.
3. Для бинарных исходников сохраняются как минимум: исходное имя, Library file_id, Library path (если есть), тип, размер, даты, generated/uploaded status; для содержательно важных документов дополнительно выгружается извлечённый текст.
4. Бинарный файл считается **не перенесённым как оригинал**, пока в GitHub нет самого `.png/.pdf/.docx/...` объекта. Manifest не должен выдаваться за бинарную копию.

## Безопасность

Репозиторий должен оставаться Private: Library содержит персональные, медицинские, юридические, финансовые, рабочие и корпоративные материалы.
