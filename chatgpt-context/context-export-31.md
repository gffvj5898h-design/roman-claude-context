## 1. Базовый язык

- `вайб` — атмосфера, ощущение, общий тон. Примеры: «думер-вайб», «чиновничий вайб». Статус: ядро.
- `муд` — состояние/режим/настроение. Примеры: «скуф-муд», «три топора муд». Ядро.
- `кринж` — неловкость, стыд, провал. Для оценки подачи/ситуации. Ядро.
- `крип / крипота` — пугающе-странное, неестественное; особенно для AI/персонажей. Ядро.
- `тильт` — состояние, когда всё уже морально развалило и начинаются кривые мувы. Пример: «администрация в тильте». Ядро.
- `W` — победа, удачный результат. Пример: «по официальке — W». Ядро.
- `L` — провал. Пример: «словили L». Ядро.
- `имба` — очень сильное/удачное; использовать дозированно. Ядро.
- `mid / мид` — посредственно, средняк. Пример: «отчёт красивый, результат mid». Ядро.
- `slay / слэй` — очень W, эффектно, удачно; чаще саркастически. Ядро.
- `lowkey` — слегка, по-тихому, если честно. Пример: «Минфин lowkey признал...». Ядро.
- `no cap` — без рофла, без вранья; дозированно. Ядро.
- `рил` — реально, действительно; фиксированная замена «реально». Ядро.
- `мач` — много; фиксированная замена «много». Ядро.
- `ту мач` — слишком; фиксированная замена «слишком». Ядро.

## 2. Персонажи и архетипы

- `NPC` — действует по скрипту, без самостоятельного мува; чиновники/пресс-релизы/формальные ответы. Ядро.
- `нормис` — обычный человек вне мемного контекста. Пример: «нормисы бы уже оффнулись». Ядро.
- `сигма` — независимый уверенный чел; сейчас чаще иронично; только с иронией. Сайд.
- `гигачад` — гиперболический сигма/идеальный уверенный чел; иронично. Сайд.
- `пикми` — отчаянно пытается понравиться/показать «я не как все»; политический/медийный контекст. Ядро.
- `скуф` — бытовая стагнация, «мне и так норм». Примеры: «скуф-инфраструктура», «скуф-муд». Ядро.
- `думер` — экзистенциальная тоска, панельки, ночь, безнадёга. Пример: «кировский думер-муд». Ядро.
- `альтушка` — альтернативная эстетика/не-нормисный образ; только как метафора. Сайд.

## 3. Действия и интернет-мувы

- `дропнуть` — выпустить/опубликовать/сказать. Примеры: «дропнули цифру», «дропаю финалку». Ядро.
- `форсить` — активно проталкивать тему/нарратив. Пример: «форсят успех». Ядро.
- `забайтить` — спровоцировать реакцию/клик/ответ. Пример: «забайтили на цифру 777». Ядро.
- `скипнуть / скип` — пропустить, отказаться. Ядро.
- `замьютить / мьютить` — замолчать, скрыть, не отвечать. Пример: «проблему замьютили». Ядро.
- `зашумить` — забить инфополе и отвлечь внимание. Пример: «зашумили ленту». Ядро.
- `загостить` — исчезнуть/перестать отвечать. Ядро.
- `флексить` — демонстративно показывать успех/статус; чаще иронично. Ядро.
- `ультануть` — применить главный/максимальный приём. Пример: «Дум ультанул». Ядро.
- `агриться` — раздражаться/резко реагировать. Ядро.
- `апнуть` — повысить/прокачать/продвинуть. Пример: «апнули проект». Ядро.
- `фармить` — накапливать/собирать. Пример: «фармить ауру». Ядро.
- `шипперить` — представлять/сводить двух персонажей/сущности; можно иронично про проекты и политиков. Сайд.
- `кенселить` — массово отменять/бойкотировать. Сайд.
- `ларпить` — изображать из себя роль/систему, которой по факту нет. Пример: «ларпить экономический рост». Ядро.

- `пон` — «понял», принятие факта. Ядро.

- `черемша` — абсурдная сущность/ситуация, которую уже бессмысленно рационализировать. Пример: «бюджетная черемша». Ядро.
- `бурмалда` — абсурд/мутная фигня/мем-объект; значение плавающее. Пример: «в бюджете какая-то бурмалда». Ядро.

## 5. Авторские конструкции КирЧиЛа

- `чиновничий дрип` — показная упаковка власти.
- `завезли чину` — громкий пиар/торжественный инфоповод.
- `бюджет броук` — хронический дефицит/финансовая слабость.
- `бюджет не инста` — красивые посты не меняют реальные бюджетные цифры.
- `три топора муд` — «777» + портвейн «три топора» + абсурд красивой цифры.
- `админка AFK` — власть/ведомство не отвечает или не действует.
- `плюс запинили, минус замьютили` — удобный показатель вынесли вперёд, неудобный спрятали.
- `гринфлаг-обёртка` — позитивная упаковка плохой/неполной картины.
- `фул редфлаг` — большая системная проблема.
- `ранний доступ / Early Access` — проект ещё не завершён, но уже активно продаётся как результат.
- `региональный бета-тест` — объект/реформа формально идёт, но результат ещё не доказан.
- `административный скуфизм` — хроническая бытовая стагнация в управлении.
- `региональный aura farming` — каски, жилетки, стройки, фотосессии и прочий публичный набор «очков крутости».
- `финансовая черемша` — противоречивые/абсурдные бюджетные истории.
- `лейм-завоз` — скучный формальный инфоповод.
- `муниципальный ларп` — имитация серьёзного управления/проекта без подтверждённого результата.
- `думер-муд` — экзистенциальная региональная тоска.
- `скуф-муд` — «так всегда было, и ладно».

## 7. Стилевые правила КирЧиЛа

1. Не превращать текст в сплошной словарь TikTok. Сильнее работает 1–3 мемных удара на нормальную конструкцию предложения.
2. Юмор строится на серьёзной подаче абсурда.
3. Не объяснять мем внутри самого поста, если он уже понятен по контексту.
4. «реально» → «рил»; «много» → «мач»; «слишком» → «ту мач».
5. Не использовать олдовый «молодёжный сленг» как основную речь.
6. «Сигма» и «гигачад» — только иронично, они уже частично скуфнулись.
7. «Чиназес» — фирменный финальный маркер статей/роликов.
8. Для политической повестки особенно приоритетны: NPC, ларпить, форсить, забайтить, lowkey, mid, aura farming, пупупу, черемша, бурмалда, броук, AFK.
9. Не писать мета-фразы в стиле «я понял формат», «что лутаем» без необходимости.
10. Держать строки плотными, без нарезки каждого слова на отдельную строку.
